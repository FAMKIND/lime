# Pre-release checklist

Things that must be done before Lime goes to testers or the App Store. Later briefs append to this list.

- [x] **Acknowledgements screen** (LIME-98). Settings → About → Acknowledgements lists every library linked into the app with its licence text, including the **SQLCipher Community Edition** notice (Zetetic LLC) that binary distribution must reproduce. The text is generated by `core/make-acknowledgements.py` into `ios/Lime/Resources/Acknowledgements.txt`: **run it again whenever dependencies change**, and re-check [`core/THIRD_PARTY.md`](../core/THIRD_PARTY.md).
- [ ] **A lawyer's glance at UniFFI's MPL-2.0 use** (a file-level copyleft build tool and runtime, statically linked; see `core/THIRD_PARTY.md`). Also covers the open MIT-or-AGPL decision ([`architecture.md`](./architecture.md), section 11).
- [ ] **Production email.** A custom SMTP sender with a verified domain (for example Resend) in the production Supabase project; the code email template, the 10-character minimum password and a 30-second (or shorter) email interval set there too; the hourly email limit sized for real use. Staging needs the same before anyone but the team can sign up.
- [ ] **Terms and Privacy.** The welcome screen links `https://famkind.com` as a placeholder for both; point them at the real pages.
- [ ] **The welcome illustration.** A placeholder (the logo) until the artwork exists.
- [ ] **In-app account deletion.** The App Store requires an account created in the app to be deletable in the app. Settings → Account has no "Delete account" yet; it must delete the profile, the keys and devices, the mailbox and the Auth user on the server, and wipe the phone. **Required before release.**
- [ ] **Terms and Privacy pages.** Settings → About links `https://limechat.org/terms` and `https://limechat.org/privacy` as placeholders; publish the real pages.
- [ ] **Donate link.** The "Donate to lime" row in Settings is hidden until `LIME_DONATE_URL` (an https address) is set when the project is generated (`LIME_DONATE_URL=https://… ./ios/generate.sh`).
