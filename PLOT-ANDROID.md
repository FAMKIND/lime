### LIME-407 → `tend-Android`: link preview cards (send and show)

**Goal:** a message with a web link gets a card (title, site, picture) built on the sender's phone and carried inside the encrypted message, exactly as iOS's LIME-106; the people who read it never visit the link.
**Survey first (read-only):** iOS `Features/Chat/LinkPreviews.swift` (`LinkPreviewMaker.firstURL/make`, the 700 ms debounce, 8 s timeout, 5 s picture timeout, 640 px JPEG, https upgrade, `OutgoingPreview`, the draft card above the field with ✕, Note to Self, the setting `lime.linkPreviews`), `ChatComposer.refreshPreview`, the card view in `MessageText`/`ChatView`; core: `store/link_preview.rs`, `send` extras `preview` (`client.rs` ~2063–2100: what the send call takes), and the `link_preview` field already on the message info Android receives (`ChatRows.kt:132` reads `message.linkPreview`; nothing draws it). 4. **Showing:** the bubble draws `message.linkPreview` (picture, title, site); tapping opens the link in the browser after the same "Opens https://…" confirm sheet iOS uses (read how iOS does it); TalkBack reads "Link: title, site". 5. Works with the rich composer: a link typed or added with the Link button counts; the first link wins; removing the link removes the draft card.
