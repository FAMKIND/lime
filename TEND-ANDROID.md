## Prototype notes (LIME-301, the end of the run, 2026-11-09 ~10:20)

**What you have:** an Android app (`android/`, Kotlin + Jetpack Compose, `com.limemessenger.lime`, minSdk 26, running LimeCore) that signs in to **staging**, lists chats, and exchanges end-to-end-encrypted text and photos with a partner "phone", plus new chat, profile and settings basics and a read-only jam tab. Everything below ran on **two headless emulators (API 26 and API 36)**; nothing has run on a real phone yet. Branch `android` (pushed, never merged; main untouched).

**How to play (5 minutes):**
1. Start an emulator (Android Studio → Device Manager, or `$ANDROID_HOME/emulator/emulator -avd lime-api36`).
2. `android/tools/staging-test-accounts.sh --push` (creates/reuses Ada and Ben, pushes fresh sessions; staging only, these two accounts only).
3. `cd android && ./gradlew installDebug`, open **lime**, tap **Use a test account → Ada Android**.
4. In a terminal: `android/tools/partner/run reset` then `android/tools/partner/run echo`. Tap the pencil (new message), search `ben_android`, tap him, and write. Ben answers each message `Ben here: got "…"`, and a photo with its size and a photo of his own. (Photos: the photo button opens the system picker; the emulator's gallery may be empty: drag an image onto the emulator window first.)
5. Try: bold (`**word**`), Reply (long-press a message), your avatar → Settings → About → a preset → Save, a profile (tap Ben's name in the chat), the jam tab (empty: Ada follows nobody), the largest font (Settings app → Display), dark mode.
**Watch/see:** `~/Desktop/lime-android-prototype/` — `*-walkthrough.mp4` (the whole flow, ~1 min, API 36) and 18 screenshots (welcome → new message → chat with bold and photos → viewer → profile → settings → jam → the largest font → dark). Re-make them any time with `android/tools/record-demo.sh`.
**Proof:** `android/tools/connected.sh` runs every instrumented test on both emulators (40 instrumented tests plus the staging chat test on each emulator, 62 unit tests) including the real **Ada ↔ Ben exchange on staging** (text, formatting, reply, photo with description, profile, settings, sign out). Staging allows 10 device registrations per hour per account, so run it at most a few times an hour.
